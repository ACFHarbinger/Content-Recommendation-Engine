Content Recommendation Engine

A high-performance, privacy-centric hybrid semantic-lexical search and AI-driven recommendation pipeline for personal media libraries — spanning anime, manga, books, movies, papers, and games.

Local-First Hybrid pgvector / Qdrant Vector Search Architecture

HYBRID RETRIEVAL PIPELINE

BGE-M3 Dense + Sparse Lexical Fusion

CRE uses a unified embedding architecture powered by BAAI/bge-m3. In a single forward pass, it generates 1024-dimensional dense vectors for reviews, notes, and abstracts alongside lexical sparse vectors for exact keyword, tag, and title matching.

  • • Dense k-NN: Cosine similarity over 1024d review/synopsis embeddings
  • • Sparse Lexical: Token BM25 matching across title, author, and tag fields
  • • Rank Fusion: Distribution-agnostic Rank Reciprocal Fusion (RRF)
GRAPH INDEX & ACORN FILTERING

HNSW & pgvector Local Storage

Candidate search utilizes HNSW graph indexing paired with ACORN metadata filtering. Filters such as status != 'watched', year ranges, or media types are evaluated inline during graph traversal, eliminating candidate drop-out issues common in post-filtering.

  • • Zero-Cloud Privacy: Runs on-disk SQLite/Qdrant local storage or Postgres pgvector
  • • Cross-Encoder Reranking: Optional bge-reranker-v2-m3 pass for precision
Multi-Factor Ranking Formula

Multiplicative Recommendation Scorer

Robust Candidate Scoring
Score = Srel × (1 + α · R) × e-λ · Δt × exp(-(ℓ - μ)2 / 2σ2) × (1 + β · Hsim)
Srel • Vector Match
Dense/Sparse fused retrieval similarity score [0..1]
R • User Rating
Item quality multiplier scaled by normalized user score
e-λΔt • Recency Decay
Exponential decay based on release/ingest temporal delta
Hsim • History Boost
Vector similarity against highly-rated watched history items

Features & Interactive CLI Commands

Subcommand Description Key Flags
recommend query TEXT Execute natural language search, hybrid candidate retrieval, scoring, & optional Claude explanation. --top-k, --format json|table, --rerank
recommend ingest --input FILE Embed and upsert JSON media items into vector store with BGE-M3 dense/sparse vectors. --batch-size
recommend sync --input FILE Incrementally update existing items in-place by UUID metadata key. --dry-run
recommend export --output FILE Export entire vector collection back into clean structured JSON format. --collection
recommend info Display active vector collection statistics, embedding models, and local database settings. -v / --verbose
